# InkFlow – Professional Diagram & Whiteboard

InkFlow is a modern browser-based whiteboard and diagram application inspired by Excalidraw and tldraw. It allows users to create diagrams, sketches, flowcharts, and presentations with an intuitive interface.

🌐 **Live Demo:** https://inflow-sigma.vercel.app/

## ✨ Features

- Draw Rectangles, Circles, Diamonds, Lines, Arrows, and Freehand sketches
- Add Text and Sticky Notes
- Extended Shapes (Cloud, Star, Cylinder, Trapezoid, Parallelogram, Speech Bubble, etc.)
- Drag & Drop Image Upload
- SVG Import Support
- Hand-Drawn (Sketch) Mode
- Smart Shape Snapping
- Anchor Points & Connector Routing
- Resize, Rotate, and Move Shapes
- Undo & Redo
- Copy, Paste & Duplicate
- Dark & Light Theme
- Auto Save using Local Storage
- Import & Export JSON
- Export Canvas as PNG
- Presentation Laser Pointer
- 3D Preview
- Mobile Responsive Design

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/sharmaa-abhi/Inflow.git
cd Inflow
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
